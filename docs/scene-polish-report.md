# Butterfly, You & Me, and Interactive Letters polish

**Date:** 2026-10-22  
**Branch:** `arena/fbde90ae-birthday-surprise-enhancement`

## Scope

Focused responsive polish for the three requested native scenes. Existing configuration, scene order, animation mechanics, and visual identity remain in place. No dependencies, API/payment/Supabase changes, runtime CDN scripts, deployments, or pull requests were introduced.

## Changes

### Butterfly reveal

- Reworked the message and supporting copy into a readable, translucent presentation panel with responsive type, line wrapping, and long-message sizing.
- Preserved configured line breaks and added safe wrapping for unusually long unbroken words.
- Put the message and Continue action in a scroll-safe normal flow rather than overlaying an absolutely positioned button on long copy.
- Retained the original canvas, intro timing, reveal timing, reduced-motion behavior, and Continue callback.

### You & Me

- Made long names wrap at name boundaries instead of leaving orphaned characters; caption spacing and actions now adapt to desktop, portrait, and landscape viewports.
- Kept Continue in the layout flow, separated from the heart and copy, with safe bottom spacing and reachable overflow scrolling.
- Limited the decorative perspective transform to the canvas layer so text and actions are not rotated or blurred.
- Added capped high-DPI canvas sizing and rebuilds particles on resize/orientation changes. Canvas/context failure retains a usable text and Continue fallback.
- Preserved the ECG introduction, particle-heart formation, petals, reveal timing, and reduced-motion static heart.

### Interactive Letters

- Kept the dynamic configured letter list and sealed-envelope grid.
- Opening an envelope now opens a native modal letter reader instead of restricting the note to the envelope's small paper area.
- The reader has an independently scrollable body with `pre-wrap` copy and safe long-word wrapping. Its header and Close/Back/Continue actions remain outside that scroll area and therefore reachable.
- Added native focus containment, Escape dismissal, backdrop dismissal, focus return to the originating envelope, and keyboard-scrollable letter content.
